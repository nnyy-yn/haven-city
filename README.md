# 栖湾市 · HAVEN CITY 0.3

一座可以建设，也可以住进去的 3D 滨海小城。当前版本为可玩的浏览器原型，使用 Three.js、TypeScript、Vite 和 Rapier。

## 开始游戏

Windows 10/11（64 位）推荐从 [GitHub 发布页](https://github.com/nnyy-yn/haven-city/releases/latest) 下载 `HavenCity-Setup-0.3.0-x64.exe`，安装后从桌面启动。运行游戏不需要 Node.js、开发服务器或外网。`HavenCity-Portable-0.3.0-x64.exe` 是免安装版。

打开游戏右上角菜单，点击 **检查更新**。安装版发现新版本后可点击下载，再确认保存并重启安装；下载不会自动开始，存档失败时会中止安装。免安装版与浏览器版提供发布页下载入口。桌面存档保存在当前 Windows 用户的本地应用数据中，升级不会主动删除存档；浏览器和桌面使用各自的存储。首个版本发布后会显示“已是最新版本”。EXE 当前没有商业代码签名证书。

直接双击本目录的 **栖湾市.html**，用 Chrome 或 Edge 打开即可游玩，场景、代码及物理引擎均包含在文件中，不需要下载素材或连接外网。首次运行请等待几秒完成 3D 场景初始化。

开发服务器已启动时，也可以访问 <http://localhost:5174/>。

## 当前玩法

- **城市规划**：铺设道路，建设花园住宅、公寓、商店、办公楼、公园、能源站、水务中心、医院、警局、矫正中心、社区学校与消防站。建筑需要紧邻道路，支持拆除与部分退款。快速拖动铺路时会自动补齐中间路段。
- **建筑升级**：住宅、商业及公共设施可升至 3 级，增加容量或岗位；升级会增加维护开支。住宅、公寓与商务楼的楼层也会增加。
- **城市模拟**：人口入住、住房容量、就业、税率、每日财政预算、供电供水、幸福度、犯罪与治安。建城目标提供奖励。
- **上帝视角指挥**：选中一位居民，右键单击地面，即可让他沿道路前往指定街区；右键拖动仍然用于旋转相机。
- **居民生活**：第三人称或第一人称步行，与居民交流并建立关系，商店用餐、认领住宅并休息、在商业设施工作、公园休闲、参加巡逻。个人钱包与市政资金分开计算。
- **走进自己的家**：认领住宅后，在附近按 `H` 进入带家具的 3D 室内。做饭、睡觉、看电视、淋浴、喝茶、照料绿植，照顾饱腹、精力、社交、愉悦和清洁五项需求。装修菜单可购置书桌与书架，支持出售家具；每种家具安装在预设位置。
- **居家工作与社交**：购置书桌后可以远程办公赚钱。与居民闲聊、赞美或送礼，关系达到 35 后，可在自己家中通过关系面板邀请一位朋友来访。
- **矫正管理**：控制是否接受收押，在均衡、康复和严格三种管理政策中选择。每日作息、矫正进度、不满度和释放人数会随模拟时间变化；政策会改变财政开支与城市安全。
- **街道车流**：车辆沿当前道路网络行驶，新建及拆除道路会更新车流路线。
- **职业与技能**：商业与科技、餐饮与创作、社区与服务三条职业路线分别积累经验，最多晋升五级，提高工作收入。烹饪、逻辑和沟通通过做饭、阅读、进修、工作与社交成长；技能会影响收入、料理和关系增进。职业面板会显示当前收入与成长效果。
- **公共服务与政策**：学校提高教育覆盖，消防站支持低成本出勤。可启用绿色城市、教育扶持、社区互助政策，在每日市政开支、资源消耗和居民生活之间取舍。
- **城市事件**：邻里节、电网维护、街区火情和社区学习日定期出现。点击城市事件入口、场景标记或按 `J` 查看，选择市政出资、亲自参与、调度消防等处理方式。事件日志记录结果并显示临时效果；定位按钮可将相机移到现场。
- **昼夜氛围**：夜晚有暖色窗灯、街灯和道路微光；火情与待处理事件具有可点选的场景标记。
- **存档**：每 45 秒安静自动保存，也可以在菜单手动保存或读取。再次打开会自动继续存档，兼容 0.1 / 0.2 版旧城市，并保存室内、家具、来访、职业、技能、事件和管理政策。本地 HTML 与开发网址使用各自的浏览器存储。

## 操作

| 操作 | 按键 / 鼠标 |
| --- | --- |
| 城市 / 第三人称 / 第一人称 | `1` / `2` / `3`，或顶部视角按钮 |
| 城市平移 / 人物行走 | `W A S D` 或方向键 |
| 城市旋转 / 人物转向 | `Q` / `E` |
| 拖动视角 | 按住鼠标右键拖动 |
| 城市缩放 | 鼠标滚轮 |
| 城市拖动平移 | 左键拖动空地（选择模式）或中键拖动 |
| 选择建筑 / 居民 | 左键点击 |
| 指挥选中居民 | 城市视角中右键单击地面 |
| 建造 | 在底部选择建筑，再点击空地；道路支持按住左键连续铺设 |
| 暂停 / 继续时间 | `空格`，或时间控件 |
| 第一人称鼠标观察 | 点击场景进入鼠标捕获，`Esc` 退出 |
| 附近互动 | `F`，或点击互动提示 |
| 进家 / 出门 | 居民视角按 `H`，或使用住宅按钮；入户需要走到自家住宅附近 |
| 城市事件日志 | `J`，或点击城市事件入口 / 场景标记 |
| 奔跑 | `Shift` + 移动 |
| 聚焦选中对象 / 居民 | `R`，或定位按钮 |
| 道路快捷工具 | `B` |
| 取消建造 / 选择 | `Esc` |

建议先按 `2` 进入街区，在附近住宅旁按 `F` 安家，再按 `H` 打开家门。走近家具按 `F` 体验生活，装修面板可购买书桌。回到街区与居民聊天、赞美、送礼，建立关系后邀请到家；再按 `1` 回到城市，尝试建筑升级和矫正政策。

0.3 版可先打开事件日志资助邻里节，再建学校和消防站，选择一条职业持续工作。打开管理、职业或事件面板时，模拟会暂时停止，便于阅读和决定；关闭面板后恢复原有速度。

## 原型边界

此版是可以连续游玩的浏览器原型。建筑和角色为程序生成模型，住宅使用统一户型与固定家具位置；经济、居民行为、社交与矫正管理采用简化模拟。家庭世代、车辆驾驶、交通拥堵模拟、自由划分监狱房间、逐人排班与复杂案件尚未实现，画面仍属于原型制作精度。

## 开发

```powershell
pnpm install
pnpm dev --port 5174
node --experimental-strip-types --test tests/simulation.test.ts
pnpm --config.verify-deps-before-run=false run build
# 构建 Windows 安装版与免安装版
pnpm --dir desktop install --ignore-scripts
node desktop/node_modules/electron/install.js
node scripts/build-windows.mjs
```

构建命令会执行 TypeScript 检查并生成 `dist/`，随后输出可离线双击的 `栖湾市.html`。项目已带本机开发依赖时，可以直接运行，不需要重新联网安装。

Windows 制品位于 `desktop/release/`；桌面开发和发布说明见 [desktop/BUILD.md](desktop/BUILD.md)。更新渠道是公开仓库 `nnyy-yn/haven-city` 的稳定 Releases。发布后续版本时同步修改根 `package.json`、`desktop/package.json` 和 `src/release-config.json` 的版本，构建并上传安装 EXE、同名 `.blockmap`，最后上传 `latest.yml`。运行环境不内置任何 GitHub 令牌。

模拟规则在 `src/simulation.ts`，城市场景在 `src/world.ts`，室内场景与室内碰撞在 `src/interior.ts`，相机与输入在 `src/main.ts`，街区碰撞在 `src/physics.ts`，界面在 `src/ui.ts` / `src/style.css`。存档仅包含模拟状态，不包含渲染对象。
